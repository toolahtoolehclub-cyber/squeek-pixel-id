# Squeekchain Pixel ID Generator

A fun, retro pixel-art utility tool built for the Squeekchain community. 

## Features
- **Retro Design:** Pixel-art inspired neon UI.
- **Live Data:** Fetches real-time wheel RPM and distance directly from the official Squeekchain Public API.
- **Image Export:** Users can generate and download their custom "Squeek Citizen" ID card as a PNG.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- HTML2Canvas for image generation
- Squeekchain Public API (`https://api.squeekchain.com/v1/status`)
